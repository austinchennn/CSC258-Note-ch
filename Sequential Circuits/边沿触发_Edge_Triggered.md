# 边沿触发（Edge-Triggered）

## 定义

- **上升沿触发（positive-edge）**：C 从 0 变到 1 的那一瞬间，Q 更新成 D 的值。
- **下降沿触发（negative-edge）**：C 从 1 变到 0 的那一瞬间，Q 更新成 D 的值。

关键：**只在"变的那一瞬间"更新，其他时候 Q 都不动。** 这就是触发器（flip-flop）和锁存器（latch）的区别。

## 锁存器 vs 触发器

| 元件 | 什么时候 Q 会跟着 D 变 |
|---|---|
| D 锁存器 | C = 1 的**整段时间**，D 怎么变 Q 就跟着怎么变（透明） |
| 上升沿 D 触发器 | **只在** C 从 0 变 1 的那一刻；之后 C 一直是 1，D 再变也没用 |
| 下降沿 D 触发器 | **只在** C 从 1 变 0 的那一刻 |

- 锁存器是**电平触发**（level / value-triggered）：看的是 C "是不是 1"。
- 触发器是**边沿触发**（edge-triggered）：看的是 C "刚刚有没有变"。

## 例子（上升沿 D 触发器）

| 步骤 | 操作 | Q | 说明 |
|---|---|---|---|
| 1 | D = 1，C：0 → 1 | 1 | 上升沿，读到 D = 1 |
| 2 | C 保持 1，D 改成 0 | **1** | 不是边沿，不更新（如果是锁存器，这里 Q 就跟着变 0 了） |
| 3 | C：1 → 0 | 1 | 下降沿，上升沿触发器不理它 |
| 4 | C：0 → 1 | 0 | 又一个上升沿，这时才读到 D = 0 |

## 为什么需要边沿触发

锁存器是透明的：C = 1 期间，输入的变化会一路"冲"过去。

- 把 Q̄ 接回 D：C = 1 时 Q 会不停翻转（振荡），而不是只翻一次。
- 多个锁存器串联、共用一个时钟：C = 1 时输入会冲过所有锁存器，没法做到"每个时钟只往后移一位"。

边沿触发保证**每个时钟周期只更新一次**，移位寄存器、计数器这类电路才能正常工作。

## 怎么实现：主从结构（master-slave）

把两个锁存器串起来，让它们的开关时机相反，就像运河的船闸：前门开时后门关，后门开时前门关。

| 结构 | 主锁存器（master）打开的时候 | 从锁存器（slave）打开的时候 | Q 在何时变 |
|---|---|---|---|
| 下降沿 | C = 1 | C = 0 | C 从 1 变 0 |
| 上升沿 | C = 0（接 C̄） | C = 1 | C 从 0 变 1 |

- 主锁存器打开时，D 进入中间级，但从锁存器关着，Q 不变。
- 时钟一翻转，主锁存器关上，把值锁住；从锁存器打开，把这个值送到 Q。
- 任何时刻都只有一扇门开着，所以 D 永远不会直接穿到 Q。

本课程默认使用**上升沿触发**的 D 触发器。
